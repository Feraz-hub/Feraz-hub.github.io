# Feranmi Adenaya — portfolio

A responsive, buildless portfolio featuring Zentor, Blender studies, all public Feraz-hub repositories, and two interactive experiments. Designed for GitHub Pages.

## Preview

With Node.js installed, run `node scripts/serve.cjs` and open http://127.0.0.1:4173.

## Hosting

Publish the contents of this folder to a public repository named `Feraz-hub.github.io`. In Settings → Pages select “Deploy from a branch”, `main`, and `/ (root)`. The portfolio URL will be https://feraz-hub.github.io/ once GitHub finishes deploying.

## Update content

- Main content and contacts: `index.html`.
- Layout, colors and responsive styles: `style.css`.
- Repository summaries and interactive tools: `app.js`.
- Public repository snapshot: `repos.json`. Refresh with `node scripts/refresh-repos.mjs`.
- Assets and gallery captures: `assets/`.

The repository archive includes public repositories only. Forks and empty repositories are labeled. It does not expose private repository source or metadata. The snapshot was taken in October 2026.
